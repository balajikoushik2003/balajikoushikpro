Grocery Shop Website

🍎 Grocery Shop – Full Stack Web Development

Django · Python · PostgreSQL · HTML · CSS · JavaScript
Internship Project · Take It Smart Pvt. Ltd. · Aug–Oct 2023

A complete e‑commerce platform for grocery shopping. Users can register, log in, browse products by category, search, add items to cart, and checkout with secure payment. The admin panel manages inventory, orders, and users. Built with Django's MTV architecture.

📦 Features

  • User authentication: registration, login, password hashing, session management.
  • Product catalog: dynamic listing with search, filters, and pagination.
  • Shopping cart: add/remove items, quantity updates, real‑time total.
  • Checkout & payment: integrated with secure gateway (test mode).
  • Order tracking & history: users view order status and past orders.
  • Admin dashboard: manage products, categories, orders, and user data.

🧠 What we learned

  • Building RESTful APIs with Django REST Framework.
  • PostgreSQL database modeling and migrations.
  • Frontend–backend integration via AJAX and fetch.
  • Responsive design with CSS Grid / Flexbox.
  • Security: CSRF, XSS protection, HTTPS, and environment variables.

College Internship System

🧑‍🎓 College Internship Management System

Django · Python · SQLite · Bootstrap
Concept / Academic reference · 2023

A web‑based toolkit for managing internship programmes in an educational institution. Designed to facilitate communication between faculty, students, and coordinators. Students can view requirements, track progress, and interact with faculty.

📋 Core modules

  • Student portal: view internships, submit applications, track status.
  • Faculty dashboard: approve/reject applications, provide feedback.
  • Coordinator panel: manage internship listings, assign mentors, generate reports.
  • Real‑time chat: (conceptual) messaging between students and faculty.

🔧 Tech stack

  • Django models, views, templates, and URL routing.
  • Authentication with role‑based permissions (Student, Faculty, Coordinator).
  • Bootstrap 5 for responsive UI.
  • SQLite for rapid prototyping.
This project was part of the internship report framework, demonstrating full‑stack development principles.
