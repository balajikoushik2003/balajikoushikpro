Project Summary

AI-Based Smart Hydroponics System

ESP8266 · Arduino · Python · KNN · ANN · Lasso · IoT
Project Work Phase-2 (18ECP78) · Vemana Institute of Technology · 2023-24

Soil-less, self-controlled hydroponics with IoT sensors (DHT11, pH, moisture, ultrasonic). Two ESP8266 modules handle sensing and actuation. ML models (KNN, ANN, Lasso) classify sensor data to maintain optimal nutrient/pH/humidity levels. Anti-bacterial setup reduces water-borne diseases.

Project Summary

Waste Management System using IoT

Raspberry Pi 3 · Python · IR/Proximity/Moisture/Gas/Ultrasonic · IoT
Mini-Project (18ECMP68) · Vemana Institute of Technology · 2022-23

Smart waste-segregation system using Raspberry Pi 3 that automatically classifies waste into metal, dry, and wet streams. IR, inductive proximity, moisture, and gas sensors route waste to correct bins via servo motor, with LCD and buzzer alerts.

Key Results

  • Proteus simulation validated sensor-to-LCD-to-servo logic.
  • Ultrasonic sensor tracks fill level, triggers cloud upload and SMS alert.
  • Reduces manual sorting and hazardous exposure.
