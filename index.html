Project Summary

AI-Based Smart Hydroponics System

ESP8266 · Arduino · Python · KNN · ANN · Lasso Regression · IoT
Project Work Phase-2 (18ECP78) · Vemana Institute of Technology · 2023-24

A soil-less, self-controlled hydroponics system that uses an IoT sensor network (DHT11 temperature/humidity, pH sensor, moisture sensor, and ultrasonic water-level sensor) feeding two ESP8266 modules — one for sensing, one for actuation (relay, pump, horticulture LED). Sensor data is logged and classified with machine learning (KNN, ANN, and Lasso regression) to keep nutrient levels, pH, and humidity in an optimal range, with an added anti-bacterial setup to curb water-borne diseases common in hydroponic setups.

Key Results

  • Neural network classifier trained on sensor data (temperature, humidity, water level, pH) reached 99.98% test accuracy.
  • End-to-end pipeline: ESP8266 sensor readings → Java server (NetBeans) logging to CSV → ML model → mobile app status ("Normal"/"Abnormal").
  • Physical prototype built and tested with live plants, growing crops without soil using less water than traditional methods.
  • Work accepted and presented at the IEEE ICITEICS 2024 conference with positive reviewer feedback.
Project Summary

Waste Management System using IoT

Raspberry Pi 3 · Python · IR/Proximity/Moisture/Gas/Ultrasonic Sensors · IoT
Mini-Project (18ECMP68) · Vemana Institute of Technology · 2022-23

A smart waste-segregation system built around a Raspberry Pi 3 that automatically classifies waste into metal, dry, and wet streams at the point of disposal. An IR sensor detects when waste is placed, an inductive proximity sensor checks for metal, a moisture sensor distinguishes wet from dry waste, and a gas sensor flags harmful gases from wet waste — each step routed to the correct bin via a servo motor and reported on an LCD display with buzzer alerts.

Key Results

  • Working Proteus simulation validated the full sensor-to-LCD-to-servo logic (Metal/Dry/Wet detection, harmful-gas alert).
  • An ultrasonic sensor tracks bin fill level, triggering a cloud upload and SMS alert to concerned authorities once full.
  • Reduces manual sorting and lowers ragpicker exposure to hazardous waste through automatic segregation.
